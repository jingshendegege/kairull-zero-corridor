# 04 排风脊线（M06_ExhaustRidge）设计与接口合同

2026-09-28 起草。用户要求：新地图、美术与场景互动自由发挥；**关卡爽快、有部分跑酷要素**；
狙击陷阱瞄准太长需缩短。本文件同时是 Claude（关卡布局/美术/敌人美术）与 Codex（运行时后端）的分工合同。
仅本地开发分支 `codex/art-enemies-20260928`，不推送、不合并 main、不发布。

## 1. 主题与节奏

检疫设施外侧的**屋顶排风脊线**：夜间室外，远处冷却塔与城市剪影、品红航空警示灯、青色检修灯带。
玩家从屋顶检修口出发，一路向右高速穿越排风扇阵列、玻璃天窗廊、冷却塔跳台、狙击桅杆、
排气竖井攀升、高空索桥，最后在封锁泵站清场后搭塔吊撤离。

爽快原则：
- 以**流动遭遇**为主：多数房间不关门，敌人成串布置，击杀后冲刺立即刷新（本关规则），
  形成"冲刺→挥棒→冲刺"的连杀链。只有 3 个竞技场房间关门清场。
- **双路线**：上路跑酷更快（弹射扇、冲刺节点、玻璃破窗），下路更稳（普通平台/楼梯、机关）。
  不设即死坑；失误掉到下路只损失时间。
- 每段先让玩家在安全处看到新互动，再组合进战斗。

## 2. 移动度量（player.gd 现值，布局必须遵守）

60fps 帧单位：`GRAV 0.72 px/帧²`、`JUMP -13.2 px/帧`、`RUN 5.8 px/帧`。
- 普通跳最高 ≈121px（3.78 格）→ 设计可攀高差 ≤3 格；
- 平地跳远 ≈213px（6.6 格）→ 普通缝隙 ≤5 格；
- 空中冲刺 5.5 格/0.11s，冷却 1.5s；跳+冲 ≈11 格 → 需冲刺的缝隙 7–9 格，并在起跳侧可见冲刺节点或击杀目标；
- 翻滚 6 格，前 0.14s 无敌；角色约 94px 高，通道净空 ≥4 格（128px）。
- 无二段跳/蹬墙跳；不设计依赖它们的路线。

## 3. 新互动（后端由 Codex 实现；配置来自 LDtk `TacticalObjects`，坐标为世界像素）

### 3.1 `updraft_fan` 排风弹射扇
```json
{"id":"fan_1","type":"updraft_fan","pos":[x_center, floor_y],"width":64,
 "launch_height":288,"room_id":"...","purpose":"...","solutions":["..."]}
```
- 扇叶嵌在地面，`pos.y` 就是地表 y（格顶 `row*32`）；地表碰撞仍为 Solid，玩家可站立。
- 玩家脚底在 `|x-pos.x| ≤ width/2` 且落在/站在该地表上（含从空中落下）即弹射：
  竖直速度设为能到达 `launch_height` 像素高的初速度（`sqrt(2*GRAV*h)`，帧单位），同时离地。
- 同一扇 0.25s 内不重复触发；弹射不消耗、不重置冲刺冷却；时停/暂停/死亡期间不触发。
- 只作用于玩家；敌人、货箱、尸体不受影响。
- 表现：扇叶转动 + 上升气流线；由 game 统一推进（无 `_process`），时停时冻结。

### 3.2 `glass_panel` 检疫玻璃（可破）
```json
{"id":"glass_1","type":"glass_panel","rect":[x,y,w,h],"room_id":"..."}
```
- 典型 `w=32,h=128`（1×4 格竖墙），与格子对齐；布局保证 rect 内 Collision 为空。
- 完好时：阻挡玩家移动、敌人移动、敌弹（吸收）、狙击射线与敌人视线（磨砂玻璃）。
- 破碎条件：玩家**冲刺或翻滚**接触；球棒有效攻击框命中；被击飞的货箱/尸体撞到。
- 破碎：一次性，碎片粒子（有上限的池）、短顿帧（约 0.05s）、轻微镜头震动、音效（有玻璃声用玻璃声，
  否则暂用 `metal_impact`，在交付说明里写明）。冲刺穿过不减速。
- 状态：死亡重建场景自然复原；检查点恢复须与快照一致（快照时已碎的保持碎）。

### 3.3 `dash_node` 冲刺节点
```json
{"id":"node_1","type":"dash_node","pos":[x,y],"respawn":2.0,"room_id":"..."}
```
- 悬浮点，半径约 14px，`pos` 为中心。玩家身体矩形接触且冲刺处于冷却中 → 冷却清零、节点熄灭
  `respawn` 秒后重亮；冲刺可用时接触不消耗。
- 时停时不计时；死亡/检查点恢复时全部重亮。

### 3.4 本关规则：击杀刷新冲刺
boot 设 `CorridorLevel.active_kill_refresh_dash = true`（默认 false，只本关开启）：
玩家造成的敌人死亡（挥棒、货箱、玻璃连带等）立刻清零冲刺冷却。其他关卡行为不变。

## 4. 狙击陷阱缩短（Codex）

现值：跟踪 1.5s + 锁向 0.5s = 预射 2.0s，末 1s 闪线；冷却 1.5s。
新值：**跟踪 0.9s + 锁向 0.35s = 预射 1.25s**（缩短 37.5%），闪线改为预射最后 0.6s；冷却保持 1.5s。
所有地图共用（用户是在玩时觉得瞄准太长）。相关测试改为引用常量表达式、断言语义不变
（锁向期间不改方向、烟雾取消锁定、冷却不被跳过等），不得删减断言。
